製品情報

Kraken

OSS

IoTを、もっと小さく、自由に。

クラウドが重すぎる現場に、ちょうどいい選択肢。Kraken Collector と Kraken Broker を組み合わせて、IoTデータの収集・加工・保存・通知までを柔軟に構築できるオープンソースのIoTデータルーターです。

BraveJIG CLI

BraveJIGを、もっとかしこく、確実に。

BraveJIGを活用したビジネス自動化を実現するコマンドラインツールです。11種類すべてのBraveJIGセンサーモジュールに対応し、Krakenとの統合でセンサーデータを業務ワークフローへ接続できます。

BraveJIG CLIの詳細を見る

BraveJIG MCP Server

IoTに”ちょうどいい”AIを。

AIエージェントがBraveJIGのセンサーを読み、設定し、更新するためのMCPサーバーです。Claude Code、Codex、OpenClaw、LM Studioから現場のデータをそのまま扱えます。
